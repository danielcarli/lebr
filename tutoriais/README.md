# Tutoriais

Tutoriais em PDF, passo a passo, feitos com o próprio LEBR. No programa: **Ajuda → Tutorial: casa térrea simples (PDF)**
ou **Ajuda → Pasta dos tutoriais**.

| Arquivo | Conteúdo |
|---|---|
| `01-casa-terrea.pdf` | Tutorial 1 — casa térrea simples: projeto novo, pavimento e eixos, pilares, vigas em cadeia, lajes no contorno, pincel, nível de baldrame, sapatas, cálculo e correção, resultados, quantitativos e documentos. |
| `casa-terrea.lebr.json` | O projeto do tutorial 1 pronto (com a V4 já corrigida para 14 × 50 cm, como no passo 10), para comparar com o seu. |

As capturas foram feitas no LEBR 0.54/0.55 com o tema claro. Os valores de cargas, tensão no solo e seções são de
exemplo — o LEBR está em fase inicial e não deve ser usado em estruturas reais sem conferência independente.
